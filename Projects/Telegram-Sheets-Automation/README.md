# 📩 Telegram to Google Sheets Automation

## 📌 Overview

An automation workflow built with n8n that captures data from Telegram and stores it automatically in Google Sheets, eliminating manual data entry.

---

## 🚀 Features

- Telegram integration
- Automatic data collection
- Google Sheets integration
- Real-time workflow automation
- Easy to customize

---

## 🛠️ Tech Stack

- n8n
- Telegram Bot API
- Google Sheets API
- JSON Workflow
